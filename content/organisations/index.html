Organisations

Neutral, sourced pages for the organisations named on this site's conflict pages.

Back to home

Each organisation page gives the organisation's country or region, its mission in neutral terms, verifiable activities with sources, the conflict pages that reference it, and non-fundraising actions a reader can take today. Use the search box to filter the list.

All organisation pages

  • Example Reconciliation Trust — placeholder example, not a real organisation; it shows the fields an organisation page is expected to fill.

Only the placeholder example exists so far. Real organisation pages are added one at a time, each one sourced and neutral, as conflict pages come to reference them.

Adding an organisation page

  • Copy templates/organisation.html to content/organisations/<slug>.html and fill in every section.
  • Author the content from the fields in data/organisation.schema.json; data/examples/organisation-example.json is a validating example.
  • Add one <li> to the list above linking to the new file, so the page is reachable from the site.
  • Keep the relative paths used here: ../../css/styles.css, ../../js/main.js and ../../index.html.

Content is neutral and sourced. See site home for license and contribution notes.
