Organisations

Neutral, sourced pages on the organisations named in our conflict pages.

Home · Organisations

Every organisation page in this repository is listed below. Each page describes what the organisation does, links the conflict pages that reference it, and cites a published source for each activity. A page that is not in this list is unreachable for readers, so node tools/validate-pages.js fails on any file under content/organisations/ that this list does not link.

All organisations

  • Example Reconciliation Trust — worked example page showing the fields every organisation page fills. It is a template, not a real body, so it is tied to no conflict page; a real entry names its conflicts here, for example Northern Ireland or Liberia.

Real organisation pages are added alongside the conflict pages that cite them. To add one, copy templates/organisation.html to content/organisations/<slug>.html and add a line to the list above.
